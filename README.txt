
OPEN UNITY HUB → OPEN PROJECT

SETUP SCENE:

1. Create Cube → rename Platform → scale 10,1,10 → add PlatformController

2. Create Sphere → Ball → add Rigidbody → add BallController

3. Create walls (cubes)

4. Create Trap (cube) → TAG = Trap

5. Create Goal (cube) → TAG = Goal → IsTrigger ON

6. Create Checkpoint → TAG = Checkpoint → IsTrigger ON

7. Create Empty → GameManager → add GameManager script

8. Camera → position 0,15,-10

TAGS TO CREATE:
Trap
Goal
Checkpoint

CONTROLS:
Z S Q D = move
ESC = pause

PLAY → DONE
